# Product specification — V4

AI Yako Financial Intelligence Network: independent portable Django app hosted on LojasNova infrastructure temporarily. Uses LojasNova settings.py/root urls.py as integration points only, PostgreSQL for application metadata, no local database. Landing and workspace are preview UI; QVAC/WDK financial functionality is not yet connected. Target: real QVAC inference, agents, WDK testnet, local human authorization and reproducible E2E demonstration.
